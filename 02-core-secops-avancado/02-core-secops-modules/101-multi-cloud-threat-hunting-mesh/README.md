# Módulo 101: Multi-Cloud Threat Hunting Mesh e Cross-Environment Analytics

Este módulo expande o laboratório além do marco inicial, inaugurando a fase avançada com o **Multi-Cloud Threat Hunting Mesh**. Ele implementa o rastreamento, correlação e caça ativa a ameaças (Threat Hunting) distribuídas simultaneamente em ambientes híbridos e multi-cloud (AWS, Azure, GCP e infraestruturas on-premise), utilizando malhas analíticas unificadas para detecção de persistências e movimentos laterais.
