# Módulo 74: Post-Quantum Cryptography e Quantum-Resistant Protocols

Este módulo implementa algoritmos de Criptografia Pós-Quântica (PQC) e protocolos resistentes a ataques quânticos, preparando a infraestrutura para a era pós-computador quântico através do encapsulamento de chaves e assinaturas digitais padronizadas pelo NIST.
