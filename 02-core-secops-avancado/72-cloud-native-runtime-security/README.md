# Módulo 72: Cloud-Native Runtime Security e eBPF Kernel Tracing

Este módulo implementa segurança em tempo de execução nativa de nuvem utilizando rastreamento de kernel baseado em eBPF (Extended Berkeley Packet Filter). Ele monitora chamadas de sistema, abertura de arquivos sensíveis e conexões de rede de forma leve e não intrusiva diretamente no espaço do kernel.
