# Módulo 92: Zero Trust Architecture e Microsegmentation

Este módulo implementa controles fundamentais de Arquitetura Zero Trust (Zero Trust Architecture) e Microsegmentação de Rede (Microsegmentation), focando no princípio de menor privilégio, verificação contínua de identidade e dispositivo, e isolamento rigoroso de cargas de trabalho para prevenir movimentos laterais de atacantes.
