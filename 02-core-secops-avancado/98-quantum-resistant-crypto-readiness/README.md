# Módulo 98: Quantum-Resistant Cryptography e Post-Quantum Readiness

Este módulo implementa avaliações de prontidão criptográfica pós-quântica (Quantum-Resistant Cryptography e Post-Quantum Readiness), focando no inventário de algoritmos vulneráveis à computação quântica (como RSA e ECC), transição para criptografia resistente a quânticos padronizada pelo NIST e simulação de migração para esquemas baseados em reticulados (lattice-based).
