# Módulo 89: Cloud Security Posture Management (CSPM) e Compliance

Este módulo implementa controles avançados de Gerenciamento de Postura de Segurança em Nuvem (CSPM) e verificação contínua de conformidade (Compliance), focando na auditoria automatizada de recursos em nuvem, detecção de configurações incorretas (misconfigurations) e mapeamento de conformidade com frameworks regulatórios globais (CIS Benchmarks, PCI-DSS, NIST).
