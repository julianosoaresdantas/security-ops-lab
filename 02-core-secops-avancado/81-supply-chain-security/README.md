# Módulo 81: Supply Chain Security e Software Bill of Materials (SBOM)

Este módulo implementa práticas avançadas de segurança na cadeia de suprimentos de software (Supply Chain Security), focando na geração e validação de Bill of Materials (SBOM), análise de dependências de terceiros, verificação de integridade de artefatos e assinatura digital com Cosign e Sigstore.
