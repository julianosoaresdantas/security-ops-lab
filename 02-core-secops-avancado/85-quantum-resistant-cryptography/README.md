# Módulo 85: Quantum-Resistant Cryptography e Post-Quantum Security

Este módulo implementa algoritmos criptográficos resistentes a computadores quânticos (Quantum-Resistant Cryptography) e protocolos de segurança pós-quântica, focando na migração de esquemas tradicionais (como RSA e ECC) para primitivas aprovadas pelo NIST baseadas em reticulados (lattice-based) e hash para proteção de dados a longo prazo.
