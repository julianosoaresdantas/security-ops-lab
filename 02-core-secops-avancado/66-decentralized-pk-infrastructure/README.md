# Módulo 66: Decentralized Public Key Infrastructure (DPKI)

Este módulo implementa uma Infraestrutura de Chaves Públicas Descentralizada (DPKI), utilizando tecnologias baseadas em registro distribuído para gerenciamento de identidades soberanas, revogação de certificados e validação de confiança sem dependência de Autoridades Certificadoras (CAs) tradicionais centralizadas.
