# Módulo 64: CIEM - Cloud Infrastructure Entitlement Management

Este módulo implementa o gerenciamento de direitos e permissões em infraestruturas de nuvem (CIEM), auditando identidades humanas e de máquinas, analisando privilégios excessivos e aplicando o princípio do menor privilégio (PoLP) de forma automatizada em ambientes multi-cloud.
