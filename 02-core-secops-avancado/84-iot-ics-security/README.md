# Módulo 84: IoT & ICS Security e Industrial Threat Monitoring

Este módulo implementa controles de segurança para dispositivos da Internet das Coisas (IoT) e Sistemas de Controle Industrial (ICS/SCADA), focando na detecção de anomalias em protocolos industriais (como Modbus e BACnet), monitoramento de telemetria de campo e proteção de infraestruturas críticas contra intrusões.
