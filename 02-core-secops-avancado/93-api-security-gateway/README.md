# Módulo 1-93: API Security Gateway e OWASP Top 10 API Protection

Este módulo implementa controles avançados de segurança para APIs (API Security Gateway) e proteção alinhada ao OWASP Top 10 for APIs, focando na inspeção de payloads JSON/XML, validação rigorosa de tokens JWT, limitação de taxa (Rate Limiting) e detecção de ataques de quebra de controle de acesso a nível de objeto (BOLA/BROA).
