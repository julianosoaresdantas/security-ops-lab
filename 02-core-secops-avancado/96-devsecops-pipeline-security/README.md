# Módulo 96: DevSecOps Pipeline Security e Supply Chain Defense

Este módulo implementa controles de segurança integrados a pipelines de Integração e Implantação Contínua (DevSecOps Pipeline Security) e defesa da cadeia de suprimentos de software (Supply Chain Defense), focando na assinatura digital de artefatos, verificação de integridade de dependências e bloqueio de builds vulneráveis antes do deploy em produção.
