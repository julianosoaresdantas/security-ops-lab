# Módulo 97: AI/ML Security e LLM Guardrails

Este módulo implementa controles de segurança para Inteligência Artificial e Modelos de Linguagem de Grande Escala (AI/ML Security e LLM Guardrails), focando na mitigação de ataques de injeção de prompt (Prompt Injection), vazamento de dados sensíveis (Data Exfiltration), alucinações maliciosas e filtragem rigorosa de entradas e saídas em aplicações baseadas em IA.
