# Módulo 58: Decentralized Threat Intelligence e Compartilhamento P2P de IoCs

Este módulo implementa uma arquitetura de inteligência de ameaças descentralizada, permitindo o compartilhamento seguro e peer-to-peer (P2P) de Indicadores de Comprometimento (IoCs) entre nós federados sem dependência de um servidor centralizado de telemetria.
