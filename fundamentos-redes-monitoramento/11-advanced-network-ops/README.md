# Módulo 11: Descoberta de Ativos, Microsegmentação Docker e Visibilidade de Tráfego/DNS

Este módulo aprofunda a automação operacional cobrindo:
1. Descoberta de ativos e inventário de rede via Nmap.
2. Microsegmentação com redes Docker isoladas.
3. Visibilidade de tráfego de rede e consultas DNS.
